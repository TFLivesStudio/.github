# TFLives Studio · Organization Profile

This repository maintains the **public GitHub organization profile** for [TFLives Studio](https://github.com/TFLivesStudio).

The visible profile lives in [`profile/README.md`](profile/README.md).

## Design system

**Ember / Orange Edition.** A compact editorial layout with custom self-contained SVG artwork, a single warm orange accent family, high contrast graphite backgrounds, and no external badges, hosted metrics, or project showcases.

| Role | Hex |
| --- | --- |
| Graphite | `#15110F` |
| Dark brown | `#26170E` |
| Ember orange | `#FF943F` |
| Accent highlights | `#FFAC52` |
| Soft cream | `#FFF5EB` |
| Muted sand | `#D4A78C` |

All graphics live in [`assets/`](assets/) and use native SVG with local markup and accessible text alternatives in the profile README.

## Editing

- Update `profile/README.md` for copy, structure, or links.
- Update the source SVGs in `assets/` for artwork and typography.
- Keep the profile in **English** and **without featured projects**.
- Keep accent colors in the orange family for all added resources.
- Four official destinations: [Website](https://www.tflives.com/) · [Discord](https://discord.gg/tflives) · [Modrinth](https://modrinth.com/organization/tflives) · [BuiltByBit](https://builtbybit.com/members/tflives.551539/).
- Test on GitHub light/dark themes and mobile after edits.

> This visual concept is independent artwork for the organization profile, not a replacement for TFLives' official logo.
